# IdeaHive Studio — ChatGPT Project Context

Last updated: 8 November 2026

## 1. Purpose

This repository is the public-safe memory mirror for the independent ChatGPT research track of IdeaHive Studio.

ChatGPT must maintain its own research, evidence, analysis, conclusions and decisions. It must not present Claude/Opus findings as ChatGPT's independent findings.

## 2. Separate AI research tracks

- Claude/Opus has its own research workflow and records.
- ChatGPT has its own research workflow and records.
- Both may compare findings when explicitly requested.
- All comparisons must identify the source of each finding.
- The project owner makes final decisions.

## 3. Project background

IdeaHive Studio is a digital-product and publishing project involving channels such as Amazon KDP, Etsy and Gumroad.

Existing project work includes product research, market analysis, digital products, publishing workflows, marketing and Python automation.

This public repository intentionally does not contain the complete business research or private evidence.

## 4. Memory architecture

There are two separate copies:

**Private working memory:** The original ChatGPT-specific project folder. This contains full research, evidence, detailed decisions and working records.

**Public GitHub memory:** This repository. It contains only information approved for public access, stable operating instructions and a sanitized checkpoint.

The private working memory is the primary source for detailed research. The public repository is a read-only context mirror for new ChatGPT conversations.

Do not assume that the public mirror contains every research document.

## 5. ChatGPT responsibilities

- Read MASTER_PROJECT_CONTEXT.md.
- Read CURRENT_STATUS.md.
- Read LATEST_HANDOFF.md and its linked dated handoff.
- Read AUTO_SAVE_PROTOCOL.md.
- Identify the exact checkpoint and next pending task.
- Continue only the ChatGPT research track.
- Work one practical step at a time.
- Do not repeat completed work.
- Preserve research provenance.
- Distinguish verified facts, third-party estimates, opinions and assumptions.
- Ask only for genuinely missing information.

## 6. Privacy boundary

The following information is intentionally excluded from this public repository:

- Detailed niche-selection strategy.
- Competitor ASINs and ISBNs.
- Detailed competitor databases and exports.
- Private screenshots and raw research evidence.
- Confidential business decisions.
- Private account information and credentials.

Do not attempt to reconstruct missing private research from guesses.

## 7. Saving and GitHub

Read AUTO_SAVE_PROTOCOL.md before claiming anything is saved.

Anonymous public GitHub access is read-only. Reading a public file does not mean ChatGPT can modify the repository.

Track local saving and GitHub backup separately.

## 8. Permanent principle

The objective is continuity across ChatGPT conversations without losing the research track, decisions or next action.

Never confuse Claude's research with ChatGPT's independent work.
